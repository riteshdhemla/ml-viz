# Softmax + Cross-Entropy Gradient

Softmax converts raw output scores (logits) into a valid probability distribution. Paired with cross-entropy loss, the gradient takes a remarkably clean form that every neural network practitioner should know cold.

## The softmax formula and its properties

For $K$ classes with logits $\mathbf{z} = (z_1, \ldots, z_K)$:

$$
\hat{p}_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}, \qquad k = 1, \ldots, K
$$

Properties:
- All outputs positive: $\hat{p}_k > 0$
- Sum to one: $\sum_k \hat{p}_k = 1$
- Invariant to a constant offset: $\hat{p}_k(\mathbf{z} + c) = \hat{p}_k(\mathbf{z})$ for any $c$
- Differences between logits determine confidence, not absolute values

## A concrete 3-class example

Logits $\mathbf{z} = (2, 1, -1)$:

$$
e^{\mathbf{z}} \approx (7.389,\ 2.718,\ 0.368), \qquad \text{sum} \approx 10.475
$$

$$
\hat{\mathbf{p}} \approx (0.705,\ 0.259,\ 0.035)
$$

The model is 70.5% confident in class 1.

## Cross-entropy loss

For a single example with true class $y$ (integer index):

$$
\mathcal{L} = -\log \hat{p}_y = -\log \frac{e^{z_y}}{\sum_k e^{z_k}} = -z_y + \log\sum_k e^{z_k}
$$

The log-sum-exp form is used in practice because it is numerically stable.

**Numeric example** ($y = 0$ is correct): $\mathcal{L} = -\log(0.705) \approx 0.350$.

## Deriving the softmax + cross-entropy gradient

We want $\frac{\partial \mathcal{L}}{\partial z_k}$ for each logit $z_k$.

**For the correct class** $k = y$:

$$
\frac{\partial \mathcal{L}}{\partial z_y}
= \frac{\partial}{\partial z_y}\!\left(-z_y + \log\sum_j e^{z_j}\right)
= -1 + \frac{e^{z_y}}{\sum_j e^{z_j}}
= \hat{p}_y - 1
$$

**For wrong classes** $k \neq y$:

$$
\frac{\partial \mathcal{L}}{\partial z_k}
= 0 + \frac{e^{z_k}}{\sum_j e^{z_j}}
= \hat{p}_k
$$

Both cases unify:

$$
\boxed{\frac{\partial \mathcal{L}}{\partial z_k} = \hat{p}_k - \mathbb{1}[k = y]}
$$

**Interpretation:**
- Correct class ($k=y$): gradient $= \hat{p}_y - 1 \le 0$ — gradient descent pushes logit **up** until $\hat{p}_y \to 1$
- Wrong classes: gradient $= \hat{p}_k \ge 0$ — pushes logits **down**
- Gradients sum to zero: $\sum_k (\hat{p}_k - \mathbb{1}[k=y]) = 1 - 1 = 0$ — consistent with the constraint $\sum_k \hat{p}_k = 1$

## Verifying the gradient numerically

```python
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())   # subtract max for numerical stability
    return e / e.sum()

def cross_entropy_loss(z, y):
    return -np.log(softmax(z)[y])

def softmax_ce_grad(z, y):
    grad = softmax(z).copy()
    grad[y] -= 1
    return grad

z = np.array([2.0, 1.0, -1.0])
y = 0

print(f"softmax: {softmax(z).round(4)}")
print(f"loss:    {cross_entropy_loss(z, y):.4f}")
print(f"grad:    {softmax_ce_grad(z, y).round(4)}")

# Finite-difference verification
eps = 1e-5
fd = np.zeros(len(z))
for i in range(len(z)):
    z_p, z_m = z.copy(), z.copy()
    z_p[i] += eps; z_m[i] -= eps
    fd[i] = (cross_entropy_loss(z_p, y) - cross_entropy_loss(z_m, y)) / (2 * eps)

print(f"FD:      {fd.round(4)}")
print(f"Match:   {np.allclose(softmax_ce_grad(z, y), fd, atol=1e-7)}")
```

## The log-sum-exp numerical-stability trick

Direct computation of $e^{z_k}$ overflows for large logits ($e^{1000}$ is inf in float32). Subtract the maximum before exponentiating — the offset cancels in the softmax ratio:

$$
\log\sum_k e^{z_k} = z_{\max} + \log\sum_k e^{z_k - z_{\max}}
$$

Since $z_k - z_{\max} \le 0$, the exponents never overflow, and the value $e^0 = 1$ (the largest term) anchors the computation.
