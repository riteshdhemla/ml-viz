# Uplift Modeling & Causal Treatment Effects

Standard recommendation predicts who will convert. **Uplift modeling** predicts who will convert *because of* an intervention — a discount, an email, a product recommendation. The target variable is the **Individual Treatment Effect (ITE)**:

$$
\tau_i = Y_i(1) - Y_i(0)
$$

where $Y_i(1)$ is the outcome if user $i$ is treated and $Y_i(0)$ is the outcome if not. The fundamental problem: you can only observe one potential outcome per user. Uplift models estimate $\tau_i$ from A/B experiment data where treatment is randomly assigned.

## The four uplift segments

Users fall into four segments based on their behavior with and without treatment:

| Segment | No treatment | Treatment | Uplift |
|---|---|---|---|
| **Persuadables** | Would not convert | Would convert | ✅ Positive |
| **Sure things** | Would convert | Would convert | 0 |
| **Lost causes** | Would not convert | Would not convert | 0 |
| **Sleeping dogs** | Would convert | Would not convert | ❌ Negative |

The goal is to target **Persuadables** and avoid **Sleeping dogs** — users who would convert anyway (Sure things) waste budget; Sleeping dogs are made worse by the intervention (e.g., a discount that insults a loyal customer).

## S-Learner (Single Model)

Train a single model that takes both features $X$ and treatment indicator $T$ as inputs:

$$
\mu(x, t) = \mathbb{E}[Y \mid X = x, T = t]
$$

Estimate ITE by computing the model's prediction with and without treatment:

$$
\hat{\tau}(x) = \mu(x, 1) - \mu(x, 0)
$$

**Pros:** Simple, uses all data jointly, no need for two separate models.  
**Cons:** If the treatment feature $T$ has weak main effects but strong interaction effects, regularized models may shrink its coefficient toward zero, underestimating uplift.

## T-Learner (Two Models)

Train separate models for treated and control groups:

$$
\mu_0(x) = \mathbb{E}[Y \mid X = x, T = 0], \qquad \mu_1(x) = \mathbb{E}[Y \mid X = x, T = 1]
$$

$$
\hat{\tau}(x) = \mu_1(x) - \mu_0(x)
$$

**Pros:** Each model is optimized for its own group, captures group-specific patterns.  
**Cons:** High variance when treatment/control group sizes are imbalanced; the two models may have different implicit regularization that introduces bias into $\hat{\tau}$.

## X-Learner (Cross-fitted)

Proposed by Künzel et al. (2019). Three-stage approach:

**Stage 1:** Train $\mu_0$ on control, $\mu_1$ on treated (same as T-Learner).

**Stage 2:** Compute imputed treatment effects using cross-group predictions:

$$
\tilde{\tau}_i^{(1)} = Y_i - \hat{\mu}_0(X_i) \quad \text{for treated units}
$$
$$
\tilde{\tau}_i^{(0)} = \hat{\mu}_1(X_i) - Y_i \quad \text{for control units}
$$

**Stage 3:** Train two uplift models:
- $\tau_1(x)$: regress $\tilde{\tau}^{(1)}$ on features $X$ for treated units.
- $\tau_0(x)$: regress $\tilde{\tau}^{(0)}$ on features $X$ for control units.

**Combine** using propensity score $e(x) = P(T=1 \mid X=x)$:

$$
\hat{\tau}(x) = e(x) \cdot \tau_0(x) + (1 - e(x)) \cdot \tau_1(x)
$$

**Pros:** Better performance when treatment/control sizes are very imbalanced (X-Learner upweights the larger group's estimate).  
**Cons:** Requires propensity score estimation; 3-stage pipeline is complex.

## A worked example — T-learner by hand

Suppose users split on one feature, `recent_visitor` ∈ {yes, no}, and treatment (a discount) was randomly assigned. From the experiment logs we count conversion rates in each of the four cells:

| `recent_visitor` | Control conversion $\mu_0$ | Treated conversion $\mu_1$ | Uplift $\hat\tau = \mu_1 - \mu_0$ |
|---|---|---|---|
| **yes** | 0.60 | 0.55 | **−0.05** |
| **no**  | 0.20 | 0.50 | **+0.30** |

Read the two rows against the four segments:

- **`recent_visitor = no`** → uplift **+0.30**. These users rarely convert on their own (0.20) but the discount lifts them to 0.50. **Persuadables** — spend the budget here.
- **`recent_visitor = yes`** → uplift **−0.05**. They already convert at 0.60; the discount slightly *lowers* it (perhaps it signals "you were about to pay full price"). **Sleeping dogs / sure things** — do *not* treat them.

A naïve "who will convert" model would target the `yes` group (0.60 > 0.20) — exactly backwards. Uplift targets the `no` group, because it ranks by the *effect of treating*, not the raw outcome. That single sign flip is the entire value of uplift modeling.

## In code — a T-learner with scikit-learn

The hand example above *is* a T-learner: one model per treatment arm, then subtract. With continuous features you fit two classifiers instead of counting cells:

```bash
pip install scikit-learn numpy
```

```python
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier

rng = np.random.default_rng(0)
n = 4000
X = rng.normal(size=(n, 3))                       # user features
T = rng.integers(0, 2, size=n)                     # randomized treatment
# true effect is large only when feature 0 is negative (the "persuadables")
persuadable = (X[:, 0] < 0).astype(float)
p = 0.2 + 0.3 * persuadable * T                    # treatment lifts them by 0.30
Y = (rng.random(n) < p).astype(int)                # observed conversion

# T-learner: one model per arm
m0 = GradientBoostingClassifier().fit(X[T == 0], Y[T == 0])
m1 = GradientBoostingClassifier().fit(X[T == 1], Y[T == 1])
uplift = m1.predict_proba(X)[:, 1] - m0.predict_proba(X)[:, 1]

# users the model ranks highest should be the persuadables (feature 0 < 0)
top = uplift.argsort()[::-1][:500]
print("persuadable rate in top-500 uplift:", persuadable[top].mean())  # ~ 1.0
print("persuadable rate overall          :", persuadable.mean())       # ~ 0.5
```

The top-ranked users are almost all persuadables — the model recovered *where* the treatment works. For S-learner, X-learner, and Qini/AUUC scoring out of the box, the standard libraries are `causalml` (`from causalml.inference.meta import BaseTClassifier`) and `EconML`.

## Evaluation: Qini curve and AUUC

Standard accuracy metrics are meaningless for uplift models — the true ITE is never observed. Use **ranking-based** metrics:

**Qini curve:** Sort users by predicted uplift $\hat{\tau}_i$ (descending). Plot cumulative incremental gains vs. fraction of population treated. A perfect model concentrates all Persuadables at the top.

$$
\text{Qini gain at decile } k = \frac{Y^T_{(k)}}{N^T} - \frac{Y^C_{(k)}}{N^C}
$$

**AUUC** (Area Under the Uplift Curve): normalize the Qini curve area. Higher AUUC = better uplift model.

## Causal forests

For non-parametric uplift estimation, **Causal Forests** (Wager & Athey, 2018) build an ensemble of causal trees that partition the feature space to find heterogeneous treatment effects:

$$
\hat{\tau}(x) = \text{LocalWeightedEstimator}(\{(Y_i, T_i, X_i)\}_{i: X_i \approx x})
$$

The `causalml` and `EconML` Python packages implement causal forests with confidence intervals, enabling statistical significance testing of uplift estimates.
