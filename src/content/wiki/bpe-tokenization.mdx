# Byte-Pair Encoding (BPE)

BPE, used by GPT and many modern models, builds a subword vocabulary by iteratively merging the most frequent adjacent symbol pair. It solves the **out-of-vocabulary problem**: common words become single tokens, rare words decompose into known subword pieces — nothing maps to `[UNK]`.

## The algorithm, step by step

1. Split every training word into characters plus a special end-of-word marker `</w>`: "low" → `["l","o","w","</w>"]`.
2. Start with the character vocabulary (every unique character is a token).
3. Count the frequency of every adjacent pair across all word representations, weighted by word frequency.
4. Find the most frequent pair $(a, b)$.
5. Merge all occurrences of $(a, b)$ into the new symbol $ab$ in every word.
6. Add $ab$ to the vocabulary.
7. Repeat steps 3–6 until the vocabulary reaches the target size (e.g. 50 000 tokens).

The learned **merge list** (the ordered sequence of pairs) *is* the tokenizer: to tokenize new text, apply the same merges in the same order.

## A worked trace of the merges

Training corpus: "low"×5, "lower"×2, "newest"×6.

```
Initial vocab: l o w e r n s t </w>

Pair counts:  l+o: 7  o+w: 7  w+</w>: 5  w+e: 8  ...
Best pair: (w, e) count=8  → merge to "we"

After merge 1: l o we r </w>, l o we </w>, n ewe s t </w>
Pair counts:  l+o: 7  o+we: 7  we+r: 2  we+</w>: 5  ...
Best pair: (l, o) count=7  → merge to "lo"

...continue until target vocabulary size
```

**Result:** the vocabulary learns meaningful subwords. "unhappiness" → `["un", "happi", "ness"]` — familiar subwords even if the full word was rare in training.

## Implementation from scratch

```python
vocab = {" ".join(word) + " </w>": freq
         for word, freq in [("low", 5), ("lower", 2), ("newest", 6)]}

def get_pairs(vocab):
    pairs = {}
    for word, freq in vocab.items():
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pair = (symbols[i], symbols[i+1])
            pairs[pair] = pairs.get(pair, 0) + freq
    return pairs

def merge_vocab(pair, vocab):
    new_vocab = {}
    bigram = " ".join(pair)
    replacement = "".join(pair)
    for word, freq in vocab.items():
        new_word = word.replace(bigram, replacement)
        new_vocab[new_word] = freq
    return new_vocab

num_merges = 10
for _ in range(num_merges):
    pairs = get_pairs(vocab)
    if not pairs:
        break
    best = max(pairs, key=pairs.get)
    vocab = merge_vocab(best, vocab)
    print(f"Merged {best} → {''.join(best)}")
```

## Main variants

**WordPiece** (used by BERT) is similar but merges based on language-model likelihood improvement rather than raw frequency, producing tokens prefixed with `##` for word-continuation: "unhappiness" → `["un", "##happi", "##ness"]`.

**Byte-level BPE** (GPT-2 onwards) operates on raw bytes instead of Unicode characters — the base vocabulary is exactly 256 symbols and *any* string is representable, including emoji and arbitrary Unicode.

<Callout type="info" title="Vocabulary size trade-off">
  Bigger vocabulary → shorter sequences (fewer tokens per sentence) but a larger embedding matrix and rarer token updates. GPT-2 used 50 257 tokens; modern LLMs typically use 32k–128k.
</Callout>
