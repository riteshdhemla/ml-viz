# Generalized Linear Models & GDA

Linear regression and logistic regression look different on the surface (one outputs a real number, the other a probability) but they share the same update rule and the same theoretical justification. **Generalized Linear Models (GLMs)** expose why.

## The exponential family

A distribution belongs to the **exponential family** if its density can be written as:

$$
p(y\,;\,\eta) = b(y)\,\exp\!\bigl(\eta\, T(y) - a(\eta)\bigr)
$$

- $\eta$ — the **natural (canonical) parameter**, which encodes the distribution's shape
- $T(y)$ — the **sufficient statistic** (usually just $y$)
- $a(\eta)$ — the **log-partition function** that normalizes the density
- $b(y)$ — a base measure independent of $\eta$

<Callout type="info" title="Why this matters">
  The exponential family is a single algebraic form that contains **Gaussian, Bernoulli, Poisson, Exponential, Gamma, Multinomial**, and many other distributions. Every member has a concave log-likelihood with the same clean gradient structure, so one fitting recipe covers them all, and GLMs are built exactly on top of this structure.
</Callout>

### Bernoulli as exponential family

For binary outcomes ($y \in \{0,1\}$), $y \sim \text{Bernoulli}(\phi)$:

$$
p(y;\phi) = \phi^y(1-\phi)^{1-y} = \exp\!\Bigl(y\ln\!\tfrac{\phi}{1-\phi} + \ln(1-\phi)\Bigr)
$$

So $\eta = \ln\!\frac{\phi}{1-\phi}$, i.e., the log-odds. Inverting: $\phi = \frac{1}{1+e^{-\eta}} = \sigma(\eta)$ — the sigmoid function drops out naturally.

### Gaussian as exponential family

For $y \sim \mathcal{N}(\mu, \sigma^2)$ with known $\sigma^2$:

$$
p(y;\mu) \propto \exp\!\Bigl(\mu\cdot y - \tfrac{\mu^2}{2\sigma^2}\Bigr)
$$

So $\eta = \mu$ and $T(y) = y$. The natural parameter is just the mean.

### Poisson as exponential family

For count outcomes $y \in \{0,1,2,\ldots\}$, $y \sim \text{Poisson}(\lambda)$:

$$
p(y;\lambda) = \frac{e^{-\lambda}\lambda^y}{y!} = \frac{1}{y!}\exp\!\bigl(y\ln\lambda - \lambda\bigr)
$$

So $\eta = \ln\lambda$ and the mean is $e^\eta$.

## The three GLM assumptions

A **Generalized Linear Model** makes exactly three assumptions:

1. **Distribution:** $y \mid x;\theta \sim \text{ExpFamily}(\eta)$ — the outcome follows some exponential family distribution
2. **Linear predictor:** $\eta = \theta^\top x$ — the natural parameter is a linear function of the features
3. **Prediction target:** predict $\hat{y} = E[y \mid x;\theta]$ — output the conditional mean

That's it. Plug in different distributions and you get:

| Distribution | Link function $\eta$ | Predicted mean $E[y]$ | Model |
|---|---|---|---|
| Gaussian | $\eta = \mu$ | $\theta^\top x$ | Linear regression |
| Bernoulli | $\eta = \ln\frac{p}{1-p}$ | $\sigma(\theta^\top x)$ | Logistic regression |
| Poisson | $\eta = \ln\lambda$ | $e^{\theta^\top x}$ | Poisson regression |

<Callout type="tip" title="Why they share an update rule">
  The MLE gradient for any GLM takes the form $\nabla_\theta \ell = X^\top(y - \hat{y})$ — features times residuals. Linear and logistic regression look different in their predictions but identical in their gradient structure, which is why the same gradient descent loop works for both.
</Callout>

### The loop every GLM library actually runs

Gradient descent works, but no production fitter uses it. R's `glm` and statsmodels' `GLM` both run **iteratively reweighted least squares**, which shares more than the gradient — the entire loop is identical across families, and only the inverse link and the variance function change.

**What to notice:**

- **Frame 2 — the first step is plain OLS.** Starting from $\theta = 0$, every $\eta$ is 0, so every $\mu = 1$ and every weight is 1. The reweighting only begins once the fitted means spread out.
- **Frame 3 — Newton's rate is *local*, and the numbers show both halves.** The first five iterations crawl (2.25 down to 0.28, a factor of 8 in total); the last five square the error each step (9e-2 → 1e-2 → 1e-4 → 1e-8 → 1e-15). "Quadratic convergence" describes the second half only.
- **Frame 4 — Gaussian converges in exactly one iteration**, with a second step that moves $\theta$ by 0. With the identity link the weights are all 1 and $z = y$, so the first weighted least-squares solve *is* OLS. Linear regression is not a GLM that happens to be easy; it is the case where the iteration has nothing to iterate.
- **Frame 6 — separation.** On perfectly separable logistic data the MLE does not exist, and the loop cannot tell you. It does not error or fail to converge: $\|\theta\|$ climbs to 110, the weights $\mu(1-\mu)$ collapse to $10^{-12}$, and $\det(X^\top W X)$ falls from 140 to $10^{-6}$. What you see downstream is enormous coefficients with enormous standard errors, and those standard errors come from inverting exactly that collapsing matrix.

Frame 5 is worth reading against the callout above. Gradient ascent on the same likelihood is not catastrophically slow — 83 iterations at its best learning rate against IRLS's 10. Its real cost is that the iteration count spans 18× across learning rates and fails to converge entirely at 0.5, just past the best one. IRLS has no learning rate: the step size comes from the curvature.

## Poisson regression — a new example

When outcomes are counts (number of website visits, insurance claims, traffic accidents), $y \ge 0$ and the Gaussian assumption is violated (negative predictions are meaningless). Poisson regression fits naturally:

$$
\lambda_i = e^{\theta^\top x_i}, \qquad
\ell(\theta) = \sum_i \bigl[y_i\,\theta^\top x_i - e^{\theta^\top x_i} - \ln(y_i!)\bigr]
$$

The exponential link ensures $\lambda > 0$ always. Gradient descent with $\nabla_\theta \ell = X^\top(y-\hat{y})$ — same recipe as linear and logistic.

## Gaussian Discriminant Analysis (GDA)

GLMs above are **discriminative** — they model $P(y|x)$ directly. **Gaussian Discriminant Analysis** is the generative alternative for binary classification.

**Generative idea:** model the class-conditional distributions $P(x|y)$, then use Bayes' theorem to recover $P(y|x)$.

GDA assumes:

$$
y \sim \text{Bernoulli}(\phi), \qquad
x \mid y=0 \sim \mathcal{N}(\mu_0, \Sigma), \qquad
x \mid y=1 \sim \mathcal{N}(\mu_1, \Sigma)
$$

Both classes share the same covariance $\Sigma$ (equal covariance assumption). MLEs are closed-form:

$$
\hat\phi = \frac{\sum 1\{y^{(i)}=1\}}{m}, \qquad
\hat\mu_k = \frac{\sum_{i:y^{(i)}=k} x^{(i)}}{\sum 1\{y^{(i)}=k\}}, \qquad
\hat\Sigma = \frac{1}{m}\sum_{i=1}^m (x^{(i)} - \mu_{y^{(i)}})(x^{(i)} - \mu_{y^{(i)}})^\top
$$

The posterior $P(y=1|x)$ turns out to be exactly $\sigma(\theta^\top x)$ for some $\theta$ derived from $(\phi, \mu_0, \mu_1, \Sigma)$. So GDA has a **logistic-regression-shaped decision boundary** even though it was fit as a generative model.

### Worked example — 2D data

Suppose we have two classes of 2D points:
- Class 0: clustered around $\mu_0 = (-2, 0)$
- Class 1: clustered around $\mu_1 = (+2, 0)$
- Shared covariance $\Sigma = I$

GDA fit:
1. Compute class means $\hat\mu_0 = (-2,0)$, $\hat\mu_1 = (2,0)$
2. Pool all residuals to estimate $\hat\Sigma \approx I$
3. Read off the boundary. The posterior's weight vector is $\theta = \Sigma^{-1}(\mu_1 - \mu_0) = I \cdot (4, 0) = (4, 0)$, and with balanced classes ($\phi = 0.5$) the bias is $-\tfrac{1}{2}\big(\mu_1^\top\Sigma^{-1}\mu_1 - \mu_0^\top\Sigma^{-1}\mu_0\big) = -\tfrac{1}{2}(4 - 4) = 0$. So $P(y{=}1 \mid x) = \sigma(4x_1)$, and the decision boundary $\sigma(4x_1) = 0.5$ is the vertical line $x_1 = 0$ — the perpendicular bisector of the two means.

The whole fit is a few lines of NumPy — no gradient descent anywhere:

```python
import numpy as np

rng = np.random.default_rng(0)
X0 = rng.normal([-2, 0], 1.0, size=(200, 2))   # class 0 samples
X1 = rng.normal([+2, 0], 1.0, size=(200, 2))   # class 1 samples

mu0, mu1 = X0.mean(axis=0), X1.mean(axis=0)
resid = np.vstack([X0 - mu0, X1 - mu1])
Sigma = resid.T @ resid / len(resid)            # pooled covariance

theta = np.linalg.solve(Sigma, mu1 - mu0)
print("theta:", theta.round(2))                 # ≈ [4, 0] → boundary x1 = 0
```

## GDA vs. logistic regression

| | GDA | Logistic Regression |
|---|---|---|
| **Model** | Generative: models $P(x\|y)$ | Discriminative: models $P(y\|x)$ |
| **Assumption** | Gaussians with shared $\Sigma$ | No distributional assumption on $x$ |
| **Strength** | Needs less data when assumptions hold | Robust when assumptions are wrong |
| **Boundary** | Always linear (same functional form as logistic) | Always linear |
| **Prediction** | Same sigmoid form at test time | Same sigmoid form |

<Callout type="warning" title="When to prefer each">
  If $x \mid y$ is truly Gaussian, GDA is asymptotically more efficient (lower test error with the same training set size). In practice, features are rarely Gaussian, so logistic regression usually wins — it makes no assumptions about the input distribution and only has to learn the boundary.
</Callout>

## Choosing a GLM in practice

1. **Continuous output** → linear regression (Gaussian GLM)
2. **Binary outcome** → logistic regression (Bernoulli GLM), or GDA if data is Gaussian
3. **Count outcome** (non-negative integer) → Poisson regression; negative binomial if over-dispersed
4. **Rate or duration** → Gamma or exponential GLM

The unifying message: once you pick a distribution, the GLM machinery gives you a training loss, gradient formula, and link function automatically — no need to invent them from scratch.

## Key takeaways

- The **exponential family** is a single algebraic form containing Gaussian, Bernoulli, Poisson, and many other distributions.
- **GLMs** assume (1) $y|x$ follows an exponential family, (2) $\eta = \theta^\top x$, and (3) predict the conditional mean. This unifies linear and logistic regression.
- All GLMs share the same gradient form $\nabla_\theta \ell = X^\top(y - \hat{y})$, which is why one optimizer works for all of them.
- **GDA** is the generative alternative: model $P(x|y)$ as Gaussian and recover $P(y|x)$ via Bayes. It has the same linear boundary as logistic regression but is more data-efficient when its Gaussian assumption holds.
