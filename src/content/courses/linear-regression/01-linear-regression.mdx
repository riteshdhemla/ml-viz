# Linear Regression

The simplest supervised learning task: given input features $x_1, \ldots, x_d$, predict a continuous output $y$. It is also the cleanest first trip around the [ML project loop](/wiki/ml-project-loop) — the linear model is the whole **hypothesis space**, and least squares is the **objective**.

<WikiLink slug="ml-project-loop" title="The ML Project Loop" />

<Callout type="info" title="The forecasting thread">
The site's running example (the `daily-demand` forecasting problem from the [project-loop hub](/wiki/ml-project-loop)) starts right here. Its **tabular baseline** is exactly this model: build features from the recent past ($y_{t-1}$, $y_{t-7}$) and the calendar (day-of-week), then fit them with ordinary least squares. Every later course revisits the *same* problem with a richer hypothesis space; this is trip number one.

**Real-world examples:** Predicting house prices from square footage, bedrooms, and location. Estimating a patient's blood pressure from age and weight. Forecasting sales from advertising spend.

## The model

$$
\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \cdots + w_d x_d
$$

Compactly, $\hat{y} = \mathbf{w}^\top \mathbf{x}$ where $\mathbf{w} = (w_0, w_1, \ldots, w_d)^\top$ and $\mathbf{x} = (1, x_1, \ldots, x_d)^\top$ (a leading $1$ absorbs the bias). In matrix form across $n$ examples: $\hat{\mathbf{y}} = X\mathbf{w}$, where $X \in \mathbb{R}^{n \times (d+1)}$ prepends a column of ones to the feature matrix.

Each weight $w_j$ tells you how much $y$ changes when $x_j$ increases by one unit, **holding all other features constant**. This is the key interpretation of linear regression.

<Callout type="tip" title="Intuition">
  Imagine plotting house price vs. square footage. Linear regression finds the straight line that best fits the points. The slope is $w_1$ — for each additional square foot, the predicted price increases by $w_1$ dollars.
</Callout>

## Ordinary Least Squares (OLS)

We find the weights that minimize the mean squared error (MSE):

$$
\mathcal{L}(\mathbf{w}) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \frac{1}{n} \| \mathbf{y} - X\mathbf{w} \|^2
$$

The $\frac{1}{n}$ is just a positive constant. It does not move the location of the minimum, so to keep the algebra clean we minimize the plain sum of squared errors $\| \mathbf{y} - X\mathbf{w} \|^2$ instead. The minimizer is identical.

The closed-form minimizer is obtained by expanding the squared norm, taking the gradient, setting it to zero, and solving — a four-step algebra exercise using two standard matrix-calculus identities. The result:

$$
\boxed{\;\mathbf{w}^* = (X^\top X)^{-1} X^\top \mathbf{y}\;}
$$

$(X^\top X)^{-1}$ exists when the feature columns are linearly independent; Ridge regression adds $\lambda I$ to guarantee invertibility. For the full derivation and a complete 3-point hand fit (including the $2\times2$ inversion and $R^2$ calculation), see:

<Callout type="info" title="Why closed-form matters">
  Unlike gradient descent, OLS gives the exact answer in one computation — no learning rate to tune, no convergence to monitor. The cost is an $O(d^3)$ matrix inversion, which becomes slow when $d$ is large.
</Callout>

### Residuals and $R^2$ for this fit

Using the three-point dataset $\{(1,2),\,(2,3),\,(3,5)\}$ (also used in the Python code below) (where the normal equation gives $\mathbf{w} = (w_0, w_1) = (0.333,\,1.5)$) let's verify the fit quality. A **residual** is the gap between truth and prediction, $r_i = y_i - \hat{y}_i$. Plug each $x_i$ into the fitted line:

$$
\hat{y}_1 = 0.333 + 1.5\cdot1 = 1.833, \quad
\hat{y}_2 = 0.333 + 1.5\cdot2 = 3.333, \quad
\hat{y}_3 = 0.333 + 1.5\cdot3 = 4.833
$$

$$
r_1 = 2 - 1.833 = 0.167, \quad r_2 = 3 - 3.333 = -0.333, \quad r_3 = 5 - 4.833 = 0.167
$$

The **residual sum of squares** measures leftover error:

$$
\text{SS}_{\text{res}} = \sum_i r_i^2 = 0.167^2 + (-0.333)^2 + 0.167^2 \approx 0.0278 + 0.111 + 0.0278 = 0.167
$$

The **total sum of squares** measures how much $y$ varies around its mean $\bar{y} = \frac{2+3+5}{3} = 3.333$:

$$
\text{SS}_{\text{tot}} = \sum_i (y_i - \bar{y})^2 = (2-3.333)^2 + (3-3.333)^2 + (5-3.333)^2 \approx 1.778 + 0.111 + 2.778 = 4.667
$$

The **coefficient of determination** $R^2$ is the fraction of variance the model explains:

$$
R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}} = 1 - \frac{0.167}{4.667} \approx 0.964
$$

So this line explains about **96%** of the variation in $y$. $R^2 = 1$ is a perfect fit; $R^2 = 0$ means the model does no better than always predicting the mean $\bar{y}$.

## Python implementation

```python
import numpy as np

# Data: a leading column of ones encodes the bias w0
X = np.array([[1, 1], [1, 2], [1, 3]])
y = np.array([2, 3, 5])

# Closed-form normal equation: w = (X^T X)^-1 X^T y
w = np.linalg.inv(X.T @ X) @ X.T @ y
print("Weights [w0, w1]:", w.round(3))   # [0.333 1.5]

# Predictions and residuals
y_hat = X @ w
resid = y - y_hat
print("Residuals:", resid.round(3))      # [ 0.167 -0.333  0.167]

# R^2 = 1 - SS_res / SS_tot
ss_res = (resid ** 2).sum()
ss_tot = ((y - y.mean()) ** 2).sum()
print("R^2:", round(1 - ss_res / ss_tot, 3))  # 0.964

# Predict a new point x = 4
x_new = np.array([1, 4])  # bias=1, feature=4
print("Prediction at x=4:", round(x_new @ w, 3))  # 6.333
```

## The problem: overfitting

With many features (or correlated features), $X^T X$ can be nearly singular, causing the weights to blow up. The model fits the training noise perfectly but generalizes poorly.

**Signs of overfitting in linear regression:**
- Training error is much lower than test error
- Weight magnitudes are very large
- Small changes in data cause wild weight swings

## The fix: regularization

Both symptoms — huge unstable weights and a (nearly) singular $X^\top X$ — have the same cure: **penalize weight magnitude** so the model must earn its complexity. The Ridge penalty $\lambda\|\mathbf{w}\|^2$ even repairs the algebra: its gradient adds $2\lambda\mathbf{w}$ to the normal equation, so the closed form becomes

$$
\mathbf{w}^* = (X^\top X + \lambda I)^{-1} X^\top \mathbf{y}
$$

and the $\lambda I$ term lifts every eigenvalue of $X^\top X$ above zero — the numerical fix and the statistical fix are the same fix.

How Ridge (L2) and Lasso (L1) differ (why L1 zeroes features out entirely while L2 only shrinks them, and how to choose $\lambda$) is the subject of [Regularization: Ridge & Lasso](/courses/linear-regression/03-regularization).

## Common mistakes

1. **Comparing raw weight magnitudes across features** — a weight's size depends on its feature's scale; standardize features before reading $w_j$ as importance.
2. **Evaluating on training data alone** — a high training $R^2$ with many features says little; check held-out error to catch overfitting.
3. **Assuming linear means simple** — Linear regression with polynomial features, interactions, and transforms can model complex relationships while remaining interpretable.

## Key takeaways

- Linear regression fits $y = \mathbf{w}^\top\mathbf{x}$ by minimizing squared error.
- **OLS** has a closed form: $\mathbf{w}^* = (X^\top X)^{-1}X^\top\mathbf{y}$.
- $R^2$ measures the fraction of variance explained; residuals show where the fit misses.
- Overfitting shows up as huge, unstable weights — the cure is **regularization**, covered in [Ridge & Lasso](/courses/linear-regression/03-regularization).
