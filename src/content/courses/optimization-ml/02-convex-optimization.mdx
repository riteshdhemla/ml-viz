# Convex Optimization

Convexity is the single property that transforms an optimization problem from "hard in general" to "solvable reliably." Most classic ML loss functions are convex by design — gradient descent on them always finds the global minimum.

## What is convexity?

A function $f: \mathbb{R}^n \to \mathbb{R}$ is **convex** if, for every two points $x, y$ in its domain and every $\lambda \in [0, 1]$:

$$
f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)
$$

**Geometric meaning:** any chord connecting two points on the graph lies *above* (or on) the curve. The function "curves upward."

For twice-differentiable functions there is an equivalent condition: $f$ is convex if and only if its Hessian is **positive semi-definite** (PSD) everywhere:

$$
\nabla^2 f(x) \succeq 0 \quad \forall x
$$

### Examples

| Function | Convex? | Why |
|----------|---------|-----|
| $f(x) = x^2$ | ✅ Yes | $f''(x) = 2 > 0$ |
| $f(x) = \|x\|$ | ✅ Yes | triangle inequality; $f''$ undefined at 0 but subgradient exists |
| $f(x) = \log(1 + e^x)$ | ✅ Yes | softplus; $f'' = \sigma(x)(1-\sigma(x)) > 0$ |
| $f(x) = -x^2$ | ❌ No | $f''(x) = -2 < 0$ (concave) |
| $f(x) = \sin(x)$ | ❌ No | alternates between concave and convex regions |
| $f(x) = x^3$ | ❌ No | $f''(x) = 6x$ changes sign at $x=0$ |

```python
import numpy as np
x = np.linspace(-2, 2, 400)

# Verify softplus convexity: second derivative = sigmoid * (1-sigmoid) > 0
softplus_dd = lambda x: (1/(1+np.exp(-x))) * (1 - 1/(1+np.exp(-x)))
print("softplus f'' range:", softplus_dd(x).min().round(4), "to", softplus_dd(x).max().round(4))
# All positive → convex
```

The two "sometimes" cases both land near $500$, and that is not luck. Write the endpoints as $m \pm d$ (midpoint and half-width) and expand:

$$
\tfrac{1}{2}\big(f(m+d) + f(m-d)\big) - f(m) \;=\; \tfrac{1}{2}f''(m)\,d^2 + O(d^4)
$$

The chord clears the curve exactly when the curvature **at the midpoint** is positive. For these two functions there is no $O(d^4)$ slop to argue about — the identities are exact:

$$
x^3:\;\; \text{gap} = 3md^2 \qquad\qquad \sin:\;\; \text{gap} = -\sin(m)\,(1 - \cos d)
$$

Both are negative precisely when $f''(m) < 0$, so a random pair fails the test exactly when its midpoint lands in the rose band, which covers half of each of these symmetric domains. Hence $\approx 500/1000$.

Two things worth doing with it:

1. **Straddle the inflection of $x^3$.** Put $x_1 = -2$ and $x_2 = 2$: the midpoint sits at $0$, the gap is exactly $0$, and the chord touches. Nudge either endpoint and the sign of the gap follows the sign of the midpoint, not the sign of the endpoints. Convexity is a local-curvature property being tested globally.
2. **Pick $|x|$ and watch the Hessian story break.** Its $f''$ is $0$ everywhere the derivative exists, yet it is convex — all of its curvature is concentrated at the single kink where $f''$ is undefined. Move the midpoint onto $x = 0$ and the readout says so rather than printing a zero it cannot justify. This is why the PSD-Hessian criterion is stated for *twice-differentiable* functions, and why $\ell_1$ regularization needs subgradients.

## Jensen's inequality

If $f$ is convex and $X$ is a random variable, then:

$$
f\!\left(\mathbb{E}[X]\right) \leq \mathbb{E}[f(X)]
$$

"The function of the mean is less than or equal to the mean of the function."

This is the same picture again, not a new one. Put probability $1-\lambda$ on $x_1$ and $\lambda$ on $x_2$: then $\mathbb{E}[X] = (1-\lambda)x_1 + \lambda x_2$ is the point on the axis, $\mathbb{E}[f(X)]$ is the height of the **chord** above it, and $f(\mathbb{E}[X])$ is the height of the **curve**. The λ slider above is moving a probability weight, and the vertical bar it drags along is the Jensen gap. The chord definition is Jensen restricted to two-point distributions; the general case follows by taking limits of those.

### Application: cross-entropy ≥ entropy

Let $p$ be the true distribution and $q$ the model distribution. The gap between cross-entropy and entropy is an expectation of a log-ratio, and Jensen (applied to the convex $-\log$, with expectations under $p$) pins its sign:

$$
H(p, q) - H(p) = \mathbb{E}_p\!\left[-\log \frac{q(x)}{p(x)}\right] \;\geq\; -\log \mathbb{E}_p\!\left[\frac{q(x)}{p(x)}\right] = -\log \sum_x q(x) = -\log 1 = 0
$$

So $H(p, q) \geq H(p)$, with equality only when $q = p$ — the cross-entropy loss can never beat the entropy of the truth, and the gap is exactly the KL divergence $D_{\mathrm{KL}}(p\|q)$.

### Worked example: log-sum-exp

The partition function in exponential families requires computing $\log \sum_k e^{z_k}$. Jensen gives a lower bound: for any distribution $q$ over $k$,

$$
\log \sum_k e^{z_k} = \log \sum_k q_k \frac{e^{z_k}}{q_k} \geq \sum_k q_k \left(z_k - \log q_k\right) = \mathbb{E}_q[z_k] + H(q)
$$

This is the **ELBO** (Evidence Lower BOund) that underlies variational inference.

<Callout type="info" title="Jensen numerical check">
  For $f(x) = e^x$ and $X \sim \mathcal{N}(0, 1)$: $\mathbb{E}[e^X] = e^{1/2} \approx 1.649$ (the moment-generating function), while $e^{\mathbb{E}[X]} = e^0 = 1$. Jensen is tight — $1.649 \geq 1$.
</Callout>

## Convex sets and feasible regions

A set $\mathcal{C}$ is **convex** if for any $x, y \in \mathcal{C}$ and $\lambda \in [0,1]$, the point $\lambda x + (1-\lambda)y$ is also in $\mathcal{C}$.

Relevant examples in ML:

- **Half-spaces** $\{x : a^\top x \leq b\}$ — the building block of linear constraints
- **Balls** $\{x : \|x\| \leq r\}$ — the $\ell_2$ regularization feasible set
- **Probability simplex** $\{p \geq 0 : \sum_i p_i = 1\}$ — valid distributions
- **Intersections of convex sets** are always convex, so Ridge ($\ell_2$) and Lasso ($\ell_1$) constraint balls are convex

This matters because optimization over a **convex domain** with a **convex objective** gives the strongest guarantees.

## Key theorem: local minimum = global minimum

**Theorem.** If $f$ is convex, any local minimum is a global minimum.

**Proof sketch.** Suppose $x^*$ is a local minimum but not the global minimum, so there exists $y$ with $f(y) < f(x^*)$. By convexity, for any $\lambda \in (0, 1)$:

$$
f(\lambda y + (1-\lambda)x^*) \leq \lambda f(y) + (1-\lambda)f(x^*) < f(x^*)
$$

For small enough $\lambda$, $\lambda y + (1-\lambda)x^*$ is arbitrarily close to $x^*$, which contradicts $x^*$ being a local minimum. $\square$

**Consequence:** Gradient descent on a convex loss is guaranteed to find the global minimum (given appropriate step sizes). There are no bad local minima to get stuck in.

### Logistic regression is convex

The logistic regression loss for a single example is:

$$
\ell(w) = -y \log \sigma(w^\top x) - (1-y) \log(1 - \sigma(w^\top x))
$$

where $\sigma(z) = 1/(1+e^{-z})$. The Hessian of the full training loss is:

$$
H = \sum_{i=1}^n \sigma(w^\top x_i)(1 - \sigma(w^\top x_i))\, x_i x_i^\top
$$

Each term $\sigma(1-\sigma) > 0$ is a positive scalar and $x_i x_i^\top$ is PSD, so $H \succeq 0$ for all $w$. **Logistic regression is convex** — gradient descent finds the global optimum.

```python
from sklearn.linear_model import LogisticRegression
import numpy as np

rng = np.random.default_rng(42)
X = rng.standard_normal((200, 2))
y = (X[:, 0] + X[:, 1] > 0).astype(int)

# Regardless of initialization, GD finds the same optimum
lr1 = LogisticRegression(solver='lbfgs', random_state=0).fit(X, y)
lr2 = LogisticRegression(solver='saga', random_state=99).fit(X, y)

print("Weights (lbfgs):", lr1.coef_.round(3))
print("Weights (saga) :", lr2.coef_.round(3))
# Different solvers → same answer (global minimum)
```

<Callout type="success" title="Practical guarantee">
  Because logistic regression is convex, you never need to worry about random initialization, learning rate schedules, or getting stuck in bad local minima. Any reasonable optimizer converges to the same global solution.
</Callout>

## Non-convex functions in deep learning

Neural network losses are **not convex**. Two concrete reasons:

**1. Permutation symmetry.** Swap the two hidden units in a two-neuron network: the loss is identical. A network with $H$ hidden units has $H!$ permutations — the loss has $H!$ equivalent global minima. The loss landscape is not bowl-shaped; it has many symmetric valleys.

**2. Product structure.** The output of a two-layer net is $f(x; W_1, W_2) = W_2 \sigma(W_1 x)$. Even for linear activation ($\sigma = \text{id}$), the loss involves the product $W_2 W_1$, which is non-convex in the joint parameter space (the set $\{(A, B) : AB = C\}$ is not convex).

### Why deep learning still works

Despite non-convexity:

- **Overparameterization:** modern networks have far more parameters than training examples. This creates a connected manifold of global minima, making it easier for GD to find one.
- **Implicit bias:** SGD has a built-in preference for "flat" minima (low curvature), which tend to generalize better than sharp ones.
- **Empirical observation:** in high dimensions, most critical points are saddle points, not local minima. Gradient descent tends to escape them.

<Callout type="warning" title="Non-convexity does not mean chaos">
  Deep networks are non-convex, but their landscapes are not random noise. Structured non-convexity (with benign saddle points and few poor local minima) is why training large networks works reliably in practice.
</Callout>

## Convexity-adjacent tools

When strict convexity cannot be guaranteed, weaker properties still give useful convergence results:

| Property | Definition | Convergence rate |
|----------|------------|-----------------|
| Convex | $f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$ | $O(1/k)$ (GD) |
| $\mu$-strongly convex | $f(y) \geq f(x) + \nabla f(x)^\top(y-x) + \frac{\mu}{2}\|y-x\|^2$ | $O(\rho^k)$ linear |
| $L$-smooth | $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ | needed for step-size bounds |
| Quasi-convex | sublevel sets $\{x : f(x) \leq c\}$ are convex | bisection works |

**Strong convexity** ($\mu$-SC) is the strongest: it means the function curves up at least as fast as $\frac{\mu}{2}\|x\|^2$. Ridge regression with $\lambda > 0$ is $\lambda$-strongly convex, which is why it enjoys linear convergence.

**$L$-smoothness** bounds how fast the gradient can change. The canonical GD step size is $\eta = 1/L$.

Together, $\mu$-SC + $L$-smooth gives the **condition number** $\kappa = L/\mu$; convergence requires $O(\kappa \log(1/\epsilon))$ iterations.

## Common mistakes

1. **Assuming convexity implies fast convergence.** Convexity guarantees global minima but not speed. A badly conditioned convex problem ($\kappa \gg 1$) can be extremely slow for vanilla GD.
2. **Confusing convexity of loss with convexity of predictions.** The logistic loss is convex in $w$, but the predicted probabilities $\sigma(w^\top x)$ are not linear in $w$. Composing a convex function with a non-convex one can break convexity.
3. **Checking convexity only on the loss, not the domain.** Constrained problems require convexity of *both* the objective and the feasible set.
4. **Dismissing non-convex losses as unsolvable.** Non-convexity does not mean intractable. It means you lose the global minimum guarantee, but practical methods often work extremely well.

## Key takeaways

- A function is convex when any chord lies above the curve; equivalently when the Hessian is PSD everywhere.
- **Jensen's inequality** ($f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$) underlies the KL divergence bound and the ELBO.
- For convex functions, every local minimum is a global minimum — gradient descent is provably correct.
- Logistic regression is convex (Hessian = $\sigma(1-\sigma) x x^\top \succeq 0$); neural net losses are not.
- Strong convexity ($\mu$-SC) + $L$-smoothness together give linear (exponential) convergence.
