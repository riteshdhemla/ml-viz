# Principal Component Analysis (PCA)

PCA finds the directions of **maximum variance** in the data and projects onto them. It's the most popular dimensionality reduction technique.

**Real-world examples:** Data visualization (plotting high-dimensional data in 2D), noise reduction, feature preprocessing, image compression, exploratory data analysis.

## The core idea

Given $d$-dimensional data, PCA finds $k \ll d$ orthogonal directions (principal components) that capture the most variance:

$$\text{PC1} = \arg\max_{\|\mathbf{v}\|=1} \text{Var}(\mathbf{Xv}) = \text{direction of maximum variance}$$
$$\text{PC2} = \text{direction of max variance, perpendicular to PC1}$$
$$\vdots$$

Each subsequent component captures the most remaining variance while being orthogonal to all previous components.

<Callout type="tip" title="Intuition">
  Imagine looking at a cloud of points shaped like a flat pancake in 3D. PCA finds the two directions that span the pancake's face — you can describe each point's location with just 2 coordinates instead of 3. The third dimension (thickness) doesn't carry much information.
</Callout>

## The algorithm

### Step 1: Center the data

$$\tilde{X} = X - \bar{X}$$

Subtract the mean from each feature (PCA is sensitive to mean, not scale — but standardize if features have different units).

### Step 2: Compute covariance matrix

$$C = \frac{1}{n-1} \tilde{X}^T \tilde{X}$$

The covariance matrix captures how features vary together.

### Step 3: Eigendecomposition

$$C = V \Lambda V^T$$

- $V$: eigenvectors (principal component directions)
- $\Lambda$: diagonal matrix of eigenvalues (variance explained by each component)

### Step 4: Project onto top $k$ components

$$X_{\text{reduced}} = \tilde{X} V_k$$

where $V_k$ contains the first $k$ eigenvectors.

```python
import numpy as np
from sklearn.decomposition import PCA

# Standard PCA
pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)

print(f"Explained variance: {pca.explained_variance_ratio_}")
print(f"Total variance explained: {sum(pca.explained_variance_ratio_):.3f}")
```

## Worked example

3D data with points roughly on a plane:

```python
import numpy as np

# Generate data on a tilted plane + noise
np.random.seed(42)
t = np.random.uniform(-3, 3, 100)
X_3d = np.column_stack([
    t + np.random.normal(0, 0.3, 100),
    2*t + np.random.normal(0, 0.3, 100),
    0.5*t + np.random.normal(0, 0.3, 100)
])

# PCA to 2D
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_3d)

print(f"Original shape: {X_3d.shape}")   # (100, 3)
print(f"Reduced shape: {X_2d.shape}")    # (100, 2)
print(f"Variance explained: {pca.explained_variance_ratio_}")  # ~[0.95, 0.03]
# PC1 captures 95% of variance — the data is nearly 1D!
```

## Choosing the number of components

### Cumulative explained variance

```python
pca = PCA(n_components=None)  # keep all components
pca.fit(X)

cumulative_var = np.cumsum(pca.explained_variance_ratio_)

import matplotlib.pyplot as plt
plt.figure(figsize=(8, 5))
plt.plot(range(1, len(cumulative_var)+1), cumulative_var, 'bo-')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% threshold')
plt.xlabel('Number of components')
plt.ylabel('Cumulative variance explained')
plt.title('Scree Plot')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Choose k where cumulative variance ≥ 95%
k = np.argmax(cumulative_var >= 0.95) + 1
print(f"Need {k} components for 95% variance")
```

### Scree plot

Plot eigenvalues vs component index. Look for the "elbow" — where the curve levels off. Components after the elbow explain mostly noise.

<Callout type="info" title="Rules of thumb">
  - **95% variance:** Keep components explaining ≥ 95% of total variance
  - **Kaiser criterion:** Keep components with eigenvalue > 1 (on standardized data)
  - **Scree plot:** Keep components before the elbow
</Callout>

## SVD connection

In practice, PCA is computed via **Singular Value Decomposition** (SVD), which is numerically more stable:

$$\tilde{X} = U \Sigma V^T$$

- $V$: principal component directions (same as eigenvectors of $C$)
- $\Sigma$: singular values (related to eigenvalues by $\lambda_i = s_i^2 / (n-1)$)

```python
# Manual PCA via SVD
X_centered = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)

# Vt rows are principal components
X_reduced = X_centered @ Vt[:2].T  # project onto first 2 PCs
```

## Applications

### Data visualization
Project high-dimensional data to 2D for plotting:

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler

iris = load_iris()
X_scaled = StandardScaler().fit_transform(iris.data)  # (150, 4)

pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)

plt.figure(figsize=(8, 6))
for label in [0, 1, 2]:
    mask = iris.target == label
    plt.scatter(X_2d[mask, 0], X_2d[mask, 1], label=iris.target_names[label], alpha=0.7)
plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.1%})')
plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.1%})')
plt.legend()
plt.title('Iris dataset — PCA projection')
plt.show()
```

### Noise reduction
Project to fewer components, then reconstruct:

```python
pca = PCA(n_components=10)  # keep top 10 components
X_denoised = pca.fit_transform(X_noisy)
X_reconstructed = pca.inverse_transform(X_denoised)
```

### Feature preprocessing
Before training a model on high-dimensional data:

```python
pca = PCA(n_components=50)
X_train_pca = pca.fit_transform(X_train)  # fit on train only!
X_test_pca = pca.transform(X_test)        # transform test
```

## Limitations

| ✅ Strengths | ❌ Weaknesses |
|-------------|--------------|
| Fast, well-understood | Only captures linear relationships |
| Removes multicollinearity | Maximizes variance, not class separability |
| Reduces noise | Sensitive to outliers |
| No hyperparameters | Requires feature scaling |
| Foundational technique | Components are hard to interpret |

<Callout type="warning" title="PCA maximizes variance, not accuracy">
  PCA finds directions of maximum variance, but these may not be the best for classification. If you want class-discriminative projections, use **Linear Discriminant Analysis (LDA)** instead.
</Callout>

## Common mistakes

1. **Not standardizing features** — PCA is sensitive to feature scales. A feature with range [0, 1000] will dominate over [0, 1]. Always standardize.
2. **Using PCA before train/test split** — Fit PCA on training data only, then transform both train and test. Otherwise you leak information.
3. **Keeping too many components** — If you keep all components, PCA does nothing. The whole point is reduction.
