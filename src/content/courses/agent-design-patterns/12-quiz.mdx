# Pattern Catalogue Quiz

You have now covered all 18 patterns from the Agent Design Pattern Catalogue. This quiz checks whether you can recognise each pattern in context, reason about the forces that drive the choice, and identify the right pattern for a given scenario.

Each question is drawn from the core trade-offs explored across lessons 01–08. Focus on the *why*, not just the *what* — these questions reward understanding the forces, not just memorising names.

<Callout type="info" title="Pattern catalogue recap">
  The 18 patterns span five categories: **Goal Creator** (Passive, Proactive), **Prompt/Response Optimiser**, **RAG**, **Plan Generator** (Single-path, Multi-path), **Model Querying** (One-shot, Incremental), **Reflection** (Self, Cross, Human), **Cooperation** (Voting, Role-based, Debate), and **Infrastructure** (Multimodal Guardrails, Tool/Agent Registry, Agent Adapter, Explainability). Every question maps to one of these categories.
</Callout>

## Key takeaways

- **Goal Creator** patterns differ by who initiates: the user (Passive) vs the agent from context (Proactive).
- **Reflection** cost is ordered: Self-Reflection < Cross-Reflection < Human Reflection; appropriateness follows the inverse order for high-stakes regulated tasks.
- **Voting-based Cooperation** improves accuracy only when individual agents are better than chance — this is Condorcet's jury theorem. If agents are correlated (same base model, same context), the independence assumption fails.
- **Multimodal Guardrails** belong on both sides of the LLM call: input guardrails catch adversarial inputs and prompt injection; output guardrails catch hallucinations and policy violations.
- **Plan irreversibility** is the key driver for Single-path vs Multi-path. Cheap to undo → Single-path is fine. Catastrophic to undo → Multi-path is required.
