# Backpropagation Through Time & the Vanishing Gradient

An RNN learns the same way any network does — gradient descent on a loss. But because the network is a *loop* unrolled over time, the gradient has to flow **backward through every time step**. This is **Backpropagation Through Time (BPTT)**, and it exposes the single biggest weakness of vanilla RNNs.

## Unrolling for training

To train, we unroll the RNN over the whole sequence, treating it as a very deep feed-forward network — one "layer" per time step — that happens to *share weights*. The total loss sums each step's loss:

$$
\mathcal{L} = \sum_{t=1}^{T} \mathcal{L}_t(\mathbf{y}_t, \hat{\mathbf{y}}_t)
$$

Because $W_{hh}$ is reused at every step, its gradient is the **sum of contributions from all steps**:

$$
\frac{\partial \mathcal{L}}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial \mathcal{L}_t}{\partial W_{hh}}
$$

<Callout type="tip" title="Intuition">
  BPTT is ordinary backprop on the unrolled graph. The twist: one weight matrix appears in every layer, so its update gathers a vote from every time step. Early steps get a say in the final prediction — *if* their gradient survives the trip back.
</Callout>

## The chain through time

The gradient $\partial \mathcal{L}_T / \partial \mathbf{h}_k$ requires threading the chain rule through every hidden state between $k$ and $T$, producing a **product of $T-k$ Jacobians**. One step's Jacobian is $\partial \mathbf{h}_t/\partial \mathbf{h}_{t-1} = \mathrm{diag}(\tanh'(\mathbf{a}_t))\,W_{hh}$ — where $\tanh'(\mathbf{a}_t)$ is the element-wise derivative of tanh (a vector of values in $[0,1]$), and $\mathrm{diag}(\cdot)$ builds a diagonal matrix from that vector so the multiplication scales each row of $W_{hh}$ independently. Each step back multiplies by one copy of $W_{hh}$ and one diagonal of $\tanh'$ values. ## Why gradients vanish (or explode)

Applying the submultiplicativity of norms to the product of Jacobians bounds the gap-$(T-k)$ gradient magnitude by $\lambda^{T-k}$, where $\lambda = \|W_{hh}\|$ is the spectral norm. When $\lambda < 1$ gradients **vanish** exponentially; when $\lambda > 1$ they **explode**. The $\tanh'$ factor (always $\le 1$) only ever makes vanishing worse. ## Exploding gradients: gradient clipping

Exploding gradients have a cheap, standard fix — **clip** the gradient norm before each update:

$$
\text{if } \|\mathbf{g}\| > c:\quad \mathbf{g} \leftarrow \frac{c}{\|\mathbf{g}\|}\,\mathbf{g}
$$

```python
import torch.nn as nn

# after loss.backward(), before optimizer.step():
nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

<Callout type="info" title="Clipping fixes explosions, not vanishing">
  Gradient clipping rescales an over-large gradient back to a safe norm — it stops explosions and NaNs. It does **nothing** for vanishing gradients: you cannot rescale a signal that has already decayed to zero. That problem needs an architectural fix.
</Callout>

## Truncated BPTT

For very long sequences, unrolling the entire history is too expensive in memory. **Truncated BPTT** backpropagates only through the last $k$ steps, then detaches the hidden state so the graph does not grow forever:

```python
hidden = hidden.detach()   # keep the value, drop the gradient history
```

## The real fix is architectural

You cannot tune your way out of vanishing gradients: the bound $(\|W_{hh}\|\cdot\gamma)^{T-k}$ is exponential in the gap no matter how you initialize, because *every* path back multiplies by $W_{hh}$ and $\tanh'$. The fix is to change the architecture so there is a path whose per-step Jacobian is $\approx 1$ instead of $\|W_{hh}\|\cdot\gamma$. That is exactly what LSTMs and GRUs do: their **cell state** is updated additively ($c_t \approx c_{t-1} + \text{(stuff)}$), so $\partial c_t/\partial c_{t-1} \approx 1$ and the product of Jacobians stays near 1 over long gaps — a gradient **highway**. The next lesson derives those gates.

| Problem | Symptom | Fix |
|---------|---------|-----|
| Exploding gradient | Loss → NaN, wild swings | Gradient clipping |
| Vanishing gradient | Loss plateaus, no long-range learning | LSTM / GRU (gated cells) |

## Common mistakes

1. **Clipping to "fix" vanishing** — clipping only addresses explosions.
2. **Forgetting to `detach()`** the hidden state in truncated BPTT — backprop graph grows without bound and OOMs.
3. **Blaming the learning rate** when the model can't learn long-range patterns — it's the architecture, not the step size.

## Key takeaways

- **BPTT** is backprop on the unrolled network; one weight matrix appears at every step.
- One step's Jacobian is $\partial\mathbf{h}_t/\partial\mathbf{h}_{t-1} = \mathrm{diag}(\tanh'(\mathbf{a}_t))\,W_{hh}$; the gap-$(T-k)$ gradient is a **product of $T-k$** of these.
- That product is bounded by $(\|W_{hh}\|\cdot\gamma)^{T-k}$, so gradients **vanish** (gain below 1) or **explode** (gain above 1) *exponentially* in the gap.
- $\tanh' \le 1$ only ever makes vanishing **worse**, never lifts it back.
- **Gradient clipping** fixes explosions but not vanishing; vanishing needs an architectural fix — gated cells whose Jacobian is $\approx 1$.
