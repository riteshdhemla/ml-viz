# What is a Neuron?

A biological neuron fires when its inputs — signals from other neurons — surpass a threshold.
Artificial neurons borrow this idea and make it differentiable.

## The computation

Given inputs $x_1, x_2, \ldots, x_n$, a neuron computes:

$$
y = f\!\left(\sum_{i=1}^n w_i x_i + b\right)
$$

where $w_i$ are **weights**, $b$ is a **bias**, and $f$ is an **activation function**.

<Callout type="tip" title="Intuition">
  Think of each weight as a "volume knob" — it controls how much a particular input contributes
  to the output. The bias shifts the threshold at which the neuron activates.
</Callout>

## Why do we need activation functions?

Without $f$, stacking neurons would just be matrix multiplication — a linear operation.
Activation functions introduce **non-linearity**, letting the network learn curved decision boundaries.

Common choices:

| Function | Formula | When to use |
|----------|---------|-------------|
| ReLU | $\max(0, x)$ | Default hidden layers |
| Sigmoid | $1 / (1 + e^{-x})$ | Binary output |
| Softmax | $e^{x_i} / \sum e^{x_j}$ | Multi-class output |
| Tanh | $(e^x - e^{-x}) / (e^x + e^{-x})$ | Centered outputs |
