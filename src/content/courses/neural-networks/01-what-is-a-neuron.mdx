# What is a Neuron?

A biological neuron fires when its inputs — signals from other neurons — surpass a threshold. Artificial neurons borrow this idea ([McCulloch & Pitts, 1943](https://doi.org/10.1007/BF02478259)) and make it **differentiable**, so a network of them can be trained with gradient descent. Every deep network, from a tiny classifier to GPT, is built from this one simple unit. In [project-loop](/wiki/ml-project-loop) terms this course splits neatly into two slots: stacking neurons builds the **hypothesis space** (this lesson, layers, XOR), while training them is **optimization** (gradient descent, initialization, batch norm).

<WikiLink slug="ml-project-loop" title="The ML Project Loop" />

**Real-world examples:** Image classification, spam detection, recommendation systems, language models — all stack millions of these neurons.

## The computation

Given inputs $x_1, x_2, \ldots, x_n$, a neuron computes:

$$
y = f\!\left(\sum_{i=1}^n w_i x_i + b\right)
$$

where $w_i$ are **weights**, $b$ is a **bias**, and $f$ is an **activation function**. The term inside $f$ — the weighted sum plus bias — is called the **pre-activation** $z$.

<Callout type="tip" title="Intuition">
  Think of each weight as a "volume knob" — it controls how much a particular input contributes to the output. The bias shifts the threshold at which the neuron activates, independent of any input.
</Callout>

### A fully worked forward pass

Let's push concrete numbers through a single neuron, one step at a time. Suppose the neuron has three inputs with:

$$
\mathbf{w} = [\,2,\; -1,\; 0.5\,], \qquad b = 1, \qquad \mathbf{x} = [\,3,\; 2,\; 4\,]
$$

**Step 1 — the dot product, term by term.** The weighted sum $\mathbf{w}\cdot\mathbf{x}$ multiplies each input by its weight and adds the results:

$$
\mathbf{w}\cdot\mathbf{x} = \underbrace{(2)(3)}_{=\,6} \;+\; \underbrace{(-1)(2)}_{=\,-2} \;+\; \underbrace{(0.5)(4)}_{=\,2} \;=\; 6 - 2 + 2 \;=\; 6
$$

**Step 2 — add the bias** to get the pre-activation $z$:

$$
z = \mathbf{w}\cdot\mathbf{x} + b = 6 + 1 = 7
$$

**Step 3 — apply the activation.** Different activations turn that same $z = 7$ into very different outputs:

$$
\text{ReLU: } y = \max(0,\,7) = 7
\qquad
\text{Sigmoid: } y = \frac{1}{1 + e^{-7}} \approx 0.999
\qquad
\text{Tanh: } y = \tanh(7) \approx 1.000
$$

Notice how sigmoid and tanh have *saturated* — once $z$ is large, pushing it higher barely changes the output. That saturation is exactly what makes their gradients vanish in deep networks ([Glorot & Bengio, 2010](https://proceedings.mlr.press/v9/glorot10a.html)).

```python
import numpy as np

def neuron(x, w, b, activation="relu"):
    z = np.dot(w, x) + b                      # pre-activation
    if activation == "relu":    return max(0.0, z), z
    if activation == "sigmoid": return 1.0 / (1.0 + np.exp(-z)), z
    if activation == "tanh":    return np.tanh(z), z
    return z, z                                # linear

y, z = neuron([3, 2, 4], [2, -1, 0.5], 1)
print("pre-activation z = {}".format(z))       # 7.0
print("output y (ReLU)  = {}".format(y))       # 7.0
```

### How changing one weight changes the output

Weights are the dials the network turns during training. Let's see the effect of nudging a *single* weight while keeping everything else fixed.

Keep $\mathbf{x} = [3, 2, 4]$ and $b = 1$, but change only $w_1$ from $2$ to $3$:

$$
z_{\text{new}} = \underbrace{(3)(3)}_{=\,9} + (-1)(2) + (0.5)(4) + 1 = 9 - 2 + 2 + 1 = 10
$$

The pre-activation jumped from $7$ to $10$ — an increase of $3$. That is no accident: because $z$ depends on $w_1$ only through the term $w_1 x_1$, increasing $w_1$ by $1$ changes $z$ by exactly $x_1 = 3$. In general:

$$
\frac{\partial z}{\partial w_i} = x_i
$$

So a weight attached to a *large* input has a *large* influence on the output — this is the very quantity gradient descent uses to decide how much to adjust each weight.

```python
z_before = np.dot([2, -1, 0.5], [3, 2, 4]) + 1   # 7.0
z_after  = np.dot([3, -1, 0.5], [3, 2, 4]) + 1   # 10.0
print("change in z = {}".format(z_after - z_before))  # 3.0 == x[0]
```

## Why do we need activation functions?

Without $f$, stacking neurons would just be matrix multiplication — and the product of linear maps is still linear. Two layers $W_2(W_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2$ collapse to a single linear map $(W_2 W_1)\mathbf{x} + \text{const}$. Activation functions introduce **non-linearity**, letting the network bend space and learn curved decision boundaries.

Common choices:

| Function | Formula | Range | When to use |
|----------|---------|-------|-------------|
| ReLU | $\max(0, x)$ | $[0, \infty)$ | Default hidden layers |
| Sigmoid | $1 / (1 + e^{-x})$ | $(0, 1)$ | Binary output / probabilities |
| Tanh | $(e^x - e^{-x}) / (e^x + e^{-x})$ | $(-1, 1)$ | Zero-centered hidden layers |
| Softmax | $e^{x_i} / \sum_j e^{x_j}$ | $(0, 1)$, sums to 1 | Multi-class output |

<Callout type="info" title="Why ReLU is the default">
  ReLU is cheap to compute and its gradient is exactly 1 for positive inputs, so it doesn't shrink gradients the way sigmoid/tanh do (which saturate near their extremes). This makes deep networks train much faster ([Nair & Hinton, 2010](https://dl.acm.org/doi/10.5555/3104322.3104425)).
</Callout>

## What a single neuron can learn

A single neuron with a sigmoid activation is **exactly logistic regression** — it can only carve the input space with a straight line (a linear decision boundary), the same limitation Rosenblatt's original perceptron had ([Rosenblatt, 1958](https://doi.org/10.1037/h0042519)). It cannot solve XOR or any problem that isn't linearly separable. That limitation is precisely why we stack neurons into **layers** and add non-linear activations: depth lets the network compose simple boundaries into complex ones.

<Callout type="info" title="Universal approximation">
  The universal approximation theorem ([Cybenko, 1989](https://doi.org/10.1007/BF02551274); [Hornik, 1991](https://doi.org/10.1016/0893-6080%2891%2990009-T)) says a single hidden layer (with enough neurons) can approximate any continuous function. We still go *deep* because depth is far more **parameter-efficient** — a deep network learns reusable, hierarchical features, while a shallow one might need exponentially many neurons.
</Callout>

## Common mistakes

1. **Forgetting the bias** — without $b$, every decision boundary is forced through the origin.
2. **Using a linear activation in hidden layers** — the whole network collapses to one linear layer.
3. **Sigmoid in deep hidden layers** — it saturates and causes vanishing gradients; prefer ReLU.

## Key takeaways

- A neuron computes a weighted sum plus bias, passed through an activation: $y = f(\mathbf{w}\cdot\mathbf{x} + b)$.
- **Weights** scale inputs; the **bias** shifts the threshold.
- The **activation** adds non-linearity — without it, depth is pointless.
- One sigmoid neuron is logistic regression; **depth + non-linearity** unlock complex functions.

- [A Logical Calculus of the Ideas Immanent in Nervous Activity](https://doi.org/10.1007/BF02478259) — McCulloch & Pitts (1943), the original artificial-neuron model as a threshold logic unit.
- [The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain](https://doi.org/10.1037/h0042519) — Rosenblatt (1958), the single-neuron linear classifier and its learning rule.
- [Rectified Linear Units Improve Restricted Boltzmann Machines](https://dl.acm.org/doi/10.5555/3104322.3104425) — Nair & Hinton (2010), why ReLU became the default hidden activation.
- [Understanding the Difficulty of Training Deep Feedforward Neural Networks](https://proceedings.mlr.press/v9/glorot10a.html) — Glorot & Bengio (2010), how sigmoid/tanh saturation stalls deep training.
- [Approximation by Superpositions of a Sigmoidal Function](https://doi.org/10.1007/BF02551274) — Cybenko (1989), the universal approximation theorem for one-hidden-layer networks.
- [Approximation Capabilities of Multilayer Feedforward Networks](https://doi.org/10.1016/0893-6080%2891%2990009-T) — Hornik (1991), the activation-agnostic generalization of universal approximation.
