# Maximum Margin Classification (SVMs)

Support Vector Machines find the separating hyperplane with the **widest possible margin** — the "street" between classes. Wider streets generalize better.

**Real-world examples:** Text classification (spam detection), bioinformatics (protein classification), handwriting recognition, image classification.

## The margin

The margin is the distance between the decision boundary and the nearest data points from each class:

$$
\text{margin} = \frac{2}{\|\mathbf{w}\|}
$$

SVMs maximize this margin subject to the constraint that all points are correctly classified:

$$
\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{subject to} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \geq 1 \quad \forall i
$$

<Callout type="tip" title="Intuition">
  Imagine you're placing a street between two neighborhoods. The wider the street, the more confident you are that new houses will be on the correct side. SVM finds the widest possible street.
</Callout>

### Worked example

Two classes in 2D:
- Class +1: $(2, 2), (3, 3)$
- Class -1: $(0, 0), (1, 0)$

The decision boundary $\mathbf{w}^T \mathbf{x} + b = 0$ with $\mathbf{w} = [1, 1]$, $b = -1.5$:

- Point $(2, 2)$: $1(2) + 1(2) - 1.5 = 2.5 \geq 1$ ✓
- Point $(0, 0)$: $1(0) + 1(0) - 1.5 = -1.5 \leq -1$ ✓

Margin = $2 / \sqrt{1^2 + 1^2} = 2 / \sqrt{2} = \sqrt{2} \approx 1.41$

```python
import numpy as np
from sklearn.svm import SVC

# Simple 2D dataset
X = np.array([[2,2], [3,3], [0,0], [1,0]])
y = np.array([1, 1, -1, -1])

# Train linear SVM
svm = SVC(kernel='linear', C=1000)  # large C = hard margin
svm.fit(X, y)

print(f"Weights: {svm.coef_[0]}")
print(f"Bias: {svm.intercept_[0]}")
print(f"Support vectors: {svm.support_vectors_}")
```

## Support vectors

Only the points closest to the boundary — the **support vectors** — define the decision boundary. All other points can be moved without changing the result.

This makes SVMs memory-efficient: at prediction time, you only need the support vectors, not the entire training set.

<Callout type="info" title="Why support vectors matter">
  In our example, only $(2,2)$ and $(0,0)$ are support vectors. Moving $(3,3)$ anywhere (as long as it stays on the correct side) doesn't change the boundary. This is why SVMs generalize well — they focus on the hardest examples.
</Callout>

## Hard margin vs soft margin

### Hard margin SVM

Used for perfectly separable data:

$$
y_i(\mathbf{w}^T \mathbf{x}_i + b) \geq 1 \quad \forall i
$$

No violations allowed. Fails if data isn't linearly separable.

### Soft margin SVM

Handles non-separable data by allowing violations ($\xi_i$):

$$
\min_{\mathbf{w}, b, \xi} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^n \xi_i
$$

subject to: $y_i(\mathbf{w}^T \mathbf{x}_i + b) \geq 1 - \xi_i$ and $\xi_i \geq 0$

The parameter $C$ controls the tradeoff:
- **Large $C$:** Few violations, narrow margin (risk of overfitting)
- **Small $C$:** More violations, wide margin (more regularization)

```python
# Compare different C values
for C in [0.01, 1, 100]:
    svm = SVC(kernel='linear', C=C)
    svm.fit(X_train, y_train)
```

<Callout type="warning" title="C is inverse of regularization">
  Unlike $\lambda$ in Ridge/Lasso (where larger = more regularization), in SVMs, larger $C$ means **less** regularization. This is confusing — just remember: $C$ = how much you care about misclassification.
</Callout>

## Hinge loss

The soft margin SVM objective can be written as:

$$
\mathcal{L} = \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^n \max(0, 1 - y_i \cdot f(\mathbf{x}_i))
$$

where $\max(0, 1 - y_i \cdot f(\mathbf{x}_i))$ is the **hinge loss**:

| $y_i \cdot f(\mathbf{x}_i)$ | Hinge Loss | Interpretation |
|----------------------------|------------|----------------|
| $\geq 1$ | 0 | Correct and confident |
| $0.5$ | 0.5 | Correct but not confident |
| $0$ | 1 | On the boundary |
| $< 0$ | $> 1$ | Misclassified |

```python
import matplotlib.pyplot as plt

z = np.linspace(-2, 3, 100)
hinge = np.maximum(0, 1 - z)
zero_one = (z < 1).astype(float)
log_loss = -np.log(np.clip(1/(1+np.exp(-z)), 0.01, 0.99))

plt.figure(figsize=(8, 5))
plt.plot(z, hinge, label='Hinge loss', linewidth=2)
plt.plot(z, zero_one, label='0-1 loss', linewidth=2, linestyle='--')
plt.plot(z, log_loss, label='Log loss', linewidth=2, linestyle=':')
plt.xlabel('y · f(x)')
plt.ylabel('Loss')
plt.legend()
plt.title('Comparison of Loss Functions')
plt.grid(True, alpha=0.3)
plt.show()
```

## SVM vs Logistic Regression

| Property | SVM | Logistic Regression |
|----------|-----|---------------------|
| Decision boundary | Maximum margin | Maximum likelihood |
| Loss function | Hinge loss | Cross-entropy |
| Support vectors | Only boundary points | All points |
| Probabilities | Not natural (need calibration) | Direct output |
| Kernel trick | Yes | No (without explicit features) |
| Outlier sensitivity | Moderate (bounded loss) | High (unbounded loss) |

<Callout type="info" title="When to use which">
  SVMs are great when you have many features and want robust margins. Logistic regression is better when you need calibrated probabilities. For large datasets (> 100K), logistic regression is typically faster.
</Callout>

## Common mistakes

1. **Forgetting to scale features** — SVMs are sensitive to feature scales. Always standardize.
2. **Not tuning C** — The default C=1 may not be optimal. Try [0.01, 0.1, 1, 10, 100].
3. **Using SVM for probability estimates** — SVMs output distances, not probabilities. Use `SVC(probability=True)` with caution (it uses cross-validation internally).

## Key takeaways

- SVM finds the separating hyperplane with the **maximum margin** to the nearest points.
- Only the **support vectors** (points on the margin) define the boundary.
- **Soft margin** ($C$) allows violations to handle noisy, overlapping data.
- **Hinge loss** is the soft-margin objective; standardize features first.
