# Matrices and Transformations

A matrix is more than a grid of numbers — it's a **function** that transforms vectors. Every layer in a neural network is a matrix multiplication followed by a nonlinearity. Understanding what matrices do geometrically makes deep learning intuitive.

## What is a matrix?

A matrix $\mathbf{A} \in \mathbb{R}^{m \times n}$ has $m$ rows and $n$ columns. It defines a linear map from $\mathbb{R}^n$ to $\mathbb{R}^m$:

$$
\mathbf{y} = \mathbf{A}\mathbf{x}, \quad \mathbf{x} \in \mathbb{R}^n,\; \mathbf{y} \in \mathbb{R}^m
$$

Each row of $\mathbf{A}$ is a dot product with $\mathbf{x}$:

$$
y_i = \mathbf{a}_i^\top \mathbf{x} = \sum_{j=1}^n A_{ij} x_j
$$

**Neural network layer:** a layer with weight matrix $\mathbf{W} \in \mathbb{R}^{d_\text{out} \times d_\text{in}}$ computes $\mathbf{W}\mathbf{x} + \mathbf{b}$ — a matrix-vector product.

## Geometric intuitions

Think of a $2\times 2$ matrix as a transformation of the 2D plane. Common transformations:

| Matrix | Effect |
|--------|--------|
| $\begin{bmatrix}2&0\\0&2\end{bmatrix}$ | Scale (stretch by 2) |
| $\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ | Rotate 90° |
| $\begin{bmatrix}1&0\\0&0\end{bmatrix}$ | Project onto x-axis |
| $\begin{bmatrix}1&1\\0&1\end{bmatrix}$ | Shear |

<Callout type="tip" title="Column perspective">
  The columns of $\mathbf{A}$ tell you where the standard basis vectors land. Column 1 is where $\mathbf{e}_1$ goes, column 2 where $\mathbf{e}_2$ goes. The whole transformation is determined by these two destinations.
</Callout>

## Matrix multiplication

For $\mathbf{A} \in \mathbb{R}^{m\times k}$ and $\mathbf{B} \in \mathbb{R}^{k\times n}$:

$$
(\mathbf{AB})_{ij} = \sum_{r=1}^k A_{ir} B_{rj}
$$

The $(i,j)$ entry is the dot product of row $i$ of $\mathbf{A}$ with column $j$ of $\mathbf{B}$.

**Key properties:**
- Not commutative: $\mathbf{AB} \neq \mathbf{BA}$ in general
- Associative: $(\mathbf{AB})\mathbf{C} = \mathbf{A}(\mathbf{BC})$
- Distributive: $\mathbf{A}(\mathbf{B}+\mathbf{C}) = \mathbf{AB} + \mathbf{AC}$

**Composing transformations:** $\mathbf{A}(\mathbf{Bx})= (\mathbf{AB})\mathbf{x}$. A deep network is a composition of many such maps.

```python
import numpy as np

A = np.array([[2, 0], [0, 3]])   # scale: x by 2, y by 3
B = np.array([[0, -1], [1, 0]])  # rotate 90°

# Apply B first, then A
AB = A @ B                        # composition
x = np.array([1.0, 0.0])

print(A @ B @ x)  # == A @ (B @ x)
```

## Transpose and symmetry

The **transpose** $\mathbf{A}^\top$ flips rows and columns: $(\mathbf{A}^\top)_{ij} = A_{ji}$.

A matrix is **symmetric** if $\mathbf{A} = \mathbf{A}^\top$. Symmetric matrices arise naturally: covariance matrices and Gram matrices ($\mathbf{X}^\top \mathbf{X}$) are always symmetric.

**Useful identities:**
$$
(\mathbf{AB})^\top = \mathbf{B}^\top \mathbf{A}^\top, \qquad (\mathbf{Ax})^\top = \mathbf{x}^\top \mathbf{A}^\top
$$

## Rank and invertibility

The **rank** of $\mathbf{A}$ is the dimension of its column space — the number of linearly independent columns.

- **Full rank:** $\text{rank}(\mathbf{A}) = \min(m, n)$. For square $n\times n$ matrices, full rank ↔ invertible.
- **Rank deficient:** some columns are redundant (linearly dependent).

A square matrix $\mathbf{A}$ is **invertible** iff $\det(\mathbf{A}) \neq 0$, and then $\mathbf{A}^{-1}$ satisfies $\mathbf{A}\mathbf{A}^{-1} = \mathbf{I}$.

<Callout type="warning" title="When matrices are not invertible">
  Rank-deficient matrices map multiple inputs to the same output — information is lost. In ML, this shows up as multicollinear features (OLS fails) or as underdetermined systems (more unknowns than equations).
</Callout>

The **OLS closed form** $\hat{\mathbf{w}} = (\mathbf{X}^\top \mathbf{X})^{-1}\mathbf{X}^\top \mathbf{y}$ requires $\mathbf{X}^\top \mathbf{X}$ to be invertible — hence why highly correlated features cause problems.

## Special matrix types in ML

| Type | Property | Where it appears |
|------|----------|-----------------|
| Identity $\mathbf{I}$ | $\mathbf{IA} = \mathbf{A}$ | Residual connections (adding $\mathbf{x}$ back) |
| Diagonal | Off-diagonal zeros | Efficient batch normalization |
| Orthogonal | $\mathbf{Q}^\top \mathbf{Q} = \mathbf{I}$ | QR decomposition, rotations |
| Positive semi-definite | $\mathbf{x}^\top \mathbf{A}\mathbf{x} \geq 0$ | Covariance matrices |

## Key takeaways

- A matrix **transforms** vectors linearly — intuit it as rotation, scaling, projection.
- Matrix multiplication chains transformations; a deep network is a long chain.
- **Rank** measures how much information a transformation preserves.
- Covariance and Gram matrices ($\mathbf{X}^\top\mathbf{X}$) are always symmetric and positive semi-definite.
