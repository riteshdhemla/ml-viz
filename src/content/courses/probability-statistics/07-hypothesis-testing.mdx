# Hypothesis Testing & p-values

Is the new model *actually* better, or did it just get lucky on the test set? Did the A/B variant *really* lift conversions, or is the 2-point gap noise? **Hypothesis testing** is the formal procedure for answering "is this effect real?" It assumes nothing interesting is happening, asks how surprising the data would be under that assumption, and rejects the assumption only when the data are surprising enough. This lesson turns the standard errors and sampling distributions from the previous lesson into decisions.

**Real-world examples:** A/B tests deciding which feature ships; clinical trials; "is this coefficient significant?" in regression; comparing two models' accuracies; every "p < 0.05" you've seen in a paper.

## Null and alternative hypotheses

A test pits two hypotheses against each other:

- **Null hypothesis $H_0$** — the "boring" default: *no effect, no difference*. It's the claim you assume true for the sake of argument, because it pins down a specific distribution to compute with. Always an equality: $\mu_A = \mu_B$, or $p = 0.5$.
- **Alternative hypothesis $H_1$** — the effect you actually care about: $\mu_A \ne \mu_B$ (two-sided) or $\mu_B > \mu_A$ (one-sided).

<Callout type="warning" title="You never 'accept' H₀ — you only fail to reject it">
  A test can **reject** $H_0$ or **fail to reject** it. Failing to reject is not proof that $H_0$ is true — you may simply lack the data to detect the effect. "Absence of evidence is not evidence of absence."
</Callout>

## The test statistic and the z-test

A **test statistic** collapses the data into one number measuring how far the observation sits from $H_0$, in units of standard error. For a sample mean under a known $\sigma$, the **z-statistic** is:

$$
z = \frac{\bar{x} - \mu_0}{\text{SE}} = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}
$$

Under $H_0$, this $z$ follows the standard normal distribution (thanks to the CLT). A large $|z|$ means the observed mean is many standard errors away from the null value — unlikely if $H_0$ holds. A **two-sample z-test** compares two groups: $z = (\bar{x}_B - \bar{x}_A)/\sqrt{\text{SE}_A^2 + \text{SE}_B^2}$.

<Callout type="info" title="z-test vs. t-test">
  Use the **z-test** when the population $\sigma$ is known or $n$ is large. When $\sigma$ is unknown and estimated from a small sample, the extra uncertainty fattens the tails: use the **t-test**, whose Student's-$t$ distribution approaches the normal as $n$ grows (beyond ~30 they're nearly identical). Same logic, slightly wider critical values.
</Callout>

## The p-value

The **p-value** is the probability, *assuming $H_0$ is true*, of observing a test statistic at least as extreme as the one you got:

$$
p = P\big(\,|Z| \ge |z_{\text{obs}}| \;\big|\; H_0\,\big)
$$

Small $p$ ⇒ the data would be very surprising under $H_0$ ⇒ evidence against it. The decision rule compares $p$ to a pre-chosen **significance level** $\alpha$ (commonly $0.05$):

- $p \le \alpha$ → **reject $H_0$** ("statistically significant")
- $p > \alpha$ → **fail to reject $H_0$**

Equivalently, reject when $|z|$ exceeds the **critical value** $z^*$. The viz shows this directly: move the observed $z$ and $\alpha$, and watch the p-value region (blue) and rejection region (rose) — you reject exactly when the blue spills past the rose boundary.

<Callout type="warning" title="What a p-value is NOT">
  $p$ is **not** the probability that $H_0$ is true, and $1-p$ is **not** the probability the effect is real — those require a prior (the Bayesian view). The p-value lives entirely inside the world where $H_0$ holds: $p = 0.03$ means "if there were truly no effect, data this extreme would arise 3% of the time," nothing more.
</Callout>

```python
import numpy as np
from math import erf, sqrt

def normal_cdf(z):
    return 0.5 * (1 + erf(z / sqrt(2)))

def z_test(x_bar, mu0, sigma, n):
    z = (x_bar - mu0) / (sigma / np.sqrt(n))   # standardize the estimate
    p = 2 * (1 - normal_cdf(abs(z)))           # two-tailed p-value
    return z, p

z, p = z_test(x_bar=105, mu0=100, sigma=20, n=64)
print(f"z = {z:.2f}, p = {p:.4f}")             # z = 2.00, p = 0.0455
print("reject H0" if p < 0.05 else "fail to reject H0")
```

## Two ways to be wrong

|  | $H_0$ true | $H_0$ false |
|---|:---:|:---:|
| **Reject $H_0$** | Type I error (rate $\alpha$) | ✓ correct (power $=1-\beta$) |
| **Fail to reject** | ✓ correct | Type II error (rate $\beta$) |

- **Type I (false positive)** — claiming an effect that isn't there; its rate is the $\alpha$ you choose.
- **Type II (false negative)** — missing a real effect; its rate $\beta$ falls as sample size or effect size grows.
- **Power** $= 1-\beta$ — the chance of detecting a real effect. More data buys power without raising $\alpha$.

This is exactly the precision/recall-style tension you tune in A/B tests: lowering $\alpha$ avoids false alarms but costs power.

## Common mistakes

1. **Reading $p$ as "probability the null is true."** It's the probability *of the data given the null*, not of the null given the data.
2. **Treating $p > \alpha$ as proof of no effect.** It only means you lacked the evidence; the effect may be real but small or your test underpowered.
3. **Confusing statistical and practical significance.** With huge $n$, a trivial $0.01\%$ effect can be "significant" yet worthless — always report the effect size and CI too.
4. **Peeking / multiple comparisons.** Checking many times or testing many variants without correction inflates the false-positive rate far above $\alpha$.

## Key takeaways

- A test pits $H_0$ (no effect, an equality) against $H_1$; you **reject** or **fail to reject** $H_0$ — never "accept" it.
- The **z-test** standardizes an estimate into $z = (\bar{x}-\mu_0)/\text{SE}$, which is standard-normal under $H_0$; use the **t-test** when $\sigma$ is unknown and $n$ is small.
- The **p-value** is $P(\text{data this extreme}\mid H_0)$; reject when $p \le \alpha$. It is not the probability that $H_0$ is true.
- Tests trade **Type I** ($\alpha$, false positive) against **Type II** ($\beta$, false negative); **power** $=1-\beta$ grows with sample and effect size.
